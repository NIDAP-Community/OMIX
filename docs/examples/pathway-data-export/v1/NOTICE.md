# Synthetic pathway export notice

This directory contains invented pathway records solely to test the OMIX
pathway data export contract. It contains no MSigDB or other third-party
pathway membership data.

`synthetic-open` is a fictional source released as CC0-1.0 for this example.
The MSigDB manifest entry is metadata-only and demonstrates that restricted
content is excluded from an open artifact. Users must obtain and use MSigDB
under its applicable terms through an authorized delivery channel.
